# Objective
Generate modular, reusable interface components following the Rakanishu Visual Identity.

# Process
1. **ATOMICITY**: Build components as isolated units with clear props/interfaces.
2. **STYLING**: Use the Obsidian/Blood-Red/Bone palette strictly.
3. **ACCESSIBILITY**: Ensure ARIA compliance and proper contrast ratios.
4. **DOCS**: Include TSDoc comments for all props and state usage.

# Constraint
Do not invent new patterns; mirror existing architecture in `src/components/`.
