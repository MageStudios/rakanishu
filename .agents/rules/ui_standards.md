# Visual Laws
- **PALETTE**: Use only Obsidian, Blood-Red, and Bone hex codes.
- **TYPOGRAPHY**: Strictly adhere to the typography defined in `.goosehints`.
- **CONSISTENCY**: All interface changes must maintain absolute consistency with the existing design system.
- **READABILITY**: Professional contrast standards are non-negotiable.

# Enforcement
Flag any CSS or Tailwind class that deviates from the established project colors.
