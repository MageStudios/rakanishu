# LOOT & MATH CHARTER
- **INFINITY LAW:** All combat/item stats MUST be Decimal objects (break_infinity.js).
- **DETERMINISM:** Every drop uses xoshiro256++ PRNG. Seed = monster.id + global.seed.
- **RARITY WEIGHTS:** 80% Normal, 15% Magic, 4.5% Rare, 0.5% Unique.
- **NAMING:** Bronze → Iron → Steel → King's → Godhand.
