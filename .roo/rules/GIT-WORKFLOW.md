# 🪃 Git Workflow & Commit Standards

## 1. BRANCHING
- Feature: `feature/short-name`
- Bugfix: `fix/issue-description`
- Refactor: `refactor/change`

## 2. COMMIT TYPES
- `feat`: New feature
- `fix`: Bug fix
- `refactor`: Code restructure
- `style`: CSS/Gothic hex changes

## 3. STEP-BY-STEP
1. `git checkout -b [branch]`
2. Implement task via Architect/Stylist.
3. `git add .` && `git commit -m "[type]: [desc]"`
4. `git push -u origin [branch]`
