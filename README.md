# Rakanishu - SolidJS Idle Game

**Framework:** SolidJS (NOT React)
**State Management:** SolidJS Stores (NOT Redux/Context)
**Styling:** Tailwind CSS with custom hex colors

## Critical: This is a SolidJS Project
- NO React patterns
- NO React hooks (useState, useEffect, etc.)
- Use SolidJS primitives: createSignal, createStore, createEffect
- Follow `.roo/rules/gothic-solid-spec.md` religiously
